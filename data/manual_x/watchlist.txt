# Radar Watchlist — مصادر مجانية تمامًا (بدون X API)
# ====================================================
#
# الحسابات التي يجمع منها الرادار. الأداة تكتشف المنصة تلقائيًا من شكل الـ handle:
#
#   @user                    → X (عبر Nitter — 12 instance بالتناوب)
#   @user.bsky.social        → Bluesky (مجاني، AT Protocol)
#   @user@instance.tld       → Mastodon (مجاني، Public API)
#
# الصيغة:
#   • # تعليق                  → يُتجاهل
#   • ## اسم_القسم            → عنوان قسم (يُستخدم كـ tag للتغريدات)
#   • @handle                   → حساب يُتابع (المنصة تُكتشف تلقائيًا)
#   • فارغ                       → يُتجاهل
#
# عدد التغريدات لكل حساب يضبط من x_auto_collect.py (افتراضي 5 للقوائم الكبيرة).
# لتفعيل X API الرسمي اختياريًا: ضع RADAR_USE_X_API=1 + X_BEARER_TOKEN في env.
